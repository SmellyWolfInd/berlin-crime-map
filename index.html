Berlin Crime Map — police reports (last 12 months) + Crime Atlas neighbourhood counts
Official layers: neighborhood fill per offense category (BZR aggregates). No address-level all-crime points published.
Scope: circle centered on Victory Column out to BER (~19.5 km; 137 neighborhoods / BZR).
Basemap: Esri World Light Gray Base (no API key).
Pins = anecdotal OSINT (auto Polizeimeldungen + hand merge; X not used), filtered by age checkboxes (last 12 months on by default; older pins toggle in the layer menu) and the Crime types filter. Timeline view animates pins by date. Extra layers: central corridor (Tiergarten / Mitte, default off), bicycle theft, Fire Department, kbO. Landmarks = Victory Column / BER / Brandenburger Tor.
Legend
■ Neighborhood fill = official Crime Atlas figures; default: all offenses per 100k residents (case-count layers per offense type in the layer menu); one colour scale (light = low, dark blue = high)
Landmarks = Victory Column / BER / Brandenburger Tor
Pin color (recency vs 2026-11-23; last 12 months shown by default, older pins via layer menu):
  ■ red = last 7 days
  ■ orange = days 8–30
  ■ yellow/gold = days 31–90
  ■ green = days 91–180
  ■ blue = days 181–365
  ■ purple = older than 365 days
Pin icons (Font Awesome Classic):
   skull = homicide / attempted homicide
   gun = shooting / firearm
   mask = armed robbery
   knife = stabbing
   people-robbery = robbery / burglary
   fire = arson / fire
   explosion = pyrotechnics / explosives
   bomb = terrorism
   bolt-lightning = infrastructure incident
   warning = threat
   heartbeat = ambulance / medical
   exclamation = other
   / orange pins = Fire Department posts (fire / rescue; layer menu, default off)
Grey halo = approximate location (street centre / area); rough pins (borough centre, street not given) are never counted in the corridor
Crime types (toolbar): show/hide pins by icon type; also applies to Timeline
Timeline (toolbar): play pins over time (cumulative or rolling 7/30/90 days)
Theme (toolbar): System / Light / Dark (dark basemap in Dark)
Analytics (toolbar): hour × weekday grid, pins per borough per month
Search, Corridor only, New (red glow = new since last build) filter all views; Copy link saves the exact view
Central corridor (Tiergarten / Mitte) (layer or Corridor only button): ~2.5 km area plus landmark areas (Tiergarten, Bundestag/Reichstag, Pariser Platz / Brandenburger Tor, Leipziger Platz, Potsdamer Platz; dashed purple); area names only; default off

"On map" also depends on the pin-age checkboxes in the layer menu. Fire Department, bicycle-theft, kbO and neighborhood fills are not filtered.
